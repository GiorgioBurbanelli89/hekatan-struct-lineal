Validación Modal — Cantilever Steel I450 (Hekatan vs ETABS)

-------------------------------------------------------------

Análisis modal analítico de una columna cantilever de acero bajo gravedad,

con comparación contra ETABS y solver hekatan-fem.

Modelo: columna vertical empotrada en la base, libre en el extremo,

L = 3 m, sección I 450×250×25×13, material A36.

 

%% 1. Datos del modelo

 

L = 3 Longitud de la columna (m)

Esteel = 200000000 Módulo de Young (kN/m²) — A36 acero

Asec = 0.0177 Área de la sección (m²) — I450

Isec = 0.0006344 Momento de inercia I33 (m⁴) — strong axis

ρ = 7849 Densidad (kg/m³) — Acero

g = 9.80665 Aceleración gravedad (m/s²)

 

%% 2. Cálculos derivados

 

m = ρ · Asec = 7849 · 0.0177 = 138.9273 Masa por unidad de longitud (kg/m)

Mtotal = m · L = 138.9273 · 3 = 416.7819 Masa total (kg)

WkN = Mtotal · g1000 = 416.7819 · 9.806651000 = 4.087234 Peso (kN)

EIkNm2 = Esteel · Isec = 200000000 · 0.0006344 = 126880 Rigidez flexural (kN·m²)

EINm2 = EIkNm2 · 1000 = 126880 · 1000 = 126880000 Rigidez flexural (N·m² — SI puro)

 

%% 3. Frecuencias naturales analíticas

Para una viga cantilever Euler-Bernoulli con masa uniformemente distribuida,

los modos naturales se derivan de la ecuación característica:

cos(β·L) · cosh(β·L) + 1 = 0

Cuyas primeras 3 raíces son β_n·L = [1.875, 4.694, 7.855].

La frecuencia natural se obtiene como:

f_n = (β_n·L)² / (2π·L²) · √(EI / m)

 

βL1 = 1.875 Primera raíz característica

βL2 = 4.694 Segunda raíz

βL3 = 7.855 Tercera raíz

 

f1 = βL122 · π · L2 ·   EINm2m = 1.87522 · 3.141593 · 32 ·   126880000138.9273 = 59.413201

f2 = βL222 · π · L2 ·   EINm2m = 4.69422 · 3.141593 · 32 ·   126880000138.9273 = 372.363051

f3 = βL322 · π · L2 ·   EINm2m = 7.85522 · 3.141593 · 32 ·   126880000138.9273 = 1042.732208

%% 5. Ratios de frecuencia (regla de oro Euler-Bernoulli)

Para cantilever Euler-Bernoulli, los ratios f_n/f_1 son constantes y

dependen solo de las raíces β_n·L:

f_2/f_1 = (4.694/1.875)² ≈ 6.27

f_3/f_1 = (7.855/1.875)² ≈ 17.55

 

r21 = f2f1 = 372.36305159.413201 = 6.267345

r31 = f3f1 = 1042.73220859.413201 = 17.550514

 

%% 6. Formas modales analíticas

Las funciones modales φ_n(x) son combinaciones de seno/coseno hiperbólicas

y trigonométricas que satisfacen las CB del cantilever:

φ_n(x) = cosh(β_n·x) − cos(β_n·x) − σ_n·(sinh(β_n·x) − sin(β_n·x))

con σ_n = (sinh(β_n·L) − sin(β_n·L)) / (cosh(β_n·L) + cos(β_n·L))

 

β1 = βL1L = 1.8753 = 0.625

β2 = βL2L = 4.6943 = 1.564667

β3 = βL3L = 7.8553 = 2.618333

 

σ1 = sinh ( β1 · L )  − sin ( β1 · L ) cosh ( β1 · L )  + cos ( β1 · L )  = sinh ( 0.625 · 3 )  − sin ( 0.625 · 3 ) cosh ( 0.625 · 3 )  + cos ( 0.625 · 3 )  = 0.7266172

σ2 = sinh ( β2 · L )  − sin ( β2 · L ) cosh ( β2 · L )  + cos ( β2 · L )  = sinh ( 1.564667 · 3 )  − sin ( 1.564667 · 3 ) cosh ( 1.564667 · 3 )  + cos ( 1.564667 · 3 )  = 0.9804545

σ3 = sinh ( β3 · L )  − sin ( β3 · L ) cosh ( β3 · L )  + cos ( β3 · L )  = sinh ( 2.618333 · 3 )  − sin ( 2.618333 · 3 ) cosh ( 2.618333 · 3 )  + cos ( 2.618333 · 3 )  = 0.999126

 

% Funciones φ_n(x) — definidas como expressions

φ1 ( x )  = cosh ( β1 · x )  − cos ( β1 · x )  − σ1 ·  ( sinh ( β1 · x )  − sin ( β1 · x )  ) 

φ2 ( x )  = cosh ( β2 · x )  − cos ( β2 · x )  − σ2 ·  ( sinh ( β2 · x )  − sin ( β2 · x )  ) 

φ3 ( x )  = cosh ( β3 · x )  − cos ( β3 · x )  − σ3 ·  ( sinh ( β3 · x )  − sin ( β3 · x )  )
