## Pregunta central del TFM

> ¿Es posible construir un solver FEM open-source que **valide bit-exact** contra ETABS, manteniendo un paradigma **paramétrico-por-código** y un workflow de **round-trip** con la herramienta industrial?

**Audiencia:** ingenieros estructurales que ya usan ETABS/SAP2000.
**Eje del valor:** ventaja sobre ETABS, no reemplazo arquitectónico.

**Alcance del TFM:**
- ✅ Lineal estático
- ✅ Lineal dinámico modal
- 🔒 No-lineal (módulo freemium futuro)

---

## Problema: validar FEM en TFM

ETABS es la **referencia de la industria** en Ecuador y la región. Cualquier herramienta nueva debe demostrar:

1. **Convergencia analítica** — frente a soluciones cerradas (Timoshenko, Euler-Bernoulli)
2. **Equivalencia con ETABS** — mismo modelo → mismos resultados (Δ < 1%)
3. **Round-trip** — exportar `.e2k` para reproducir la validación en ETABS
4. **Reproducibilidad** — código abierto, parametrizable, versionable en git

> Sin estas 4 piedras angulares, **un TFM en FEM no convence al tribunal**.

## API del solver FEM

```typescript
import {
  deform,         // Estático lineal
  analyze,        // Tensiones/momentos a partir de deformaciones
  modalAnalysis,  // Modos propios + frecuencias + masa participativa
  plateQ4Solve,   // Placas Q4 (Mindlin / Kirchhoff / Plane stress)
} from "hekatan-fem";

// Ejemplo cantilever:
const out = deform(nodes, elements,
  { supports, loads },
  { elasticities, areas, momentsOfInertiaY, momentsOfInertiaZ,
    torsionalConstants, shearAreasY, shearAreasZ, densities });

// Salidas: deformaciones por nodo + reacciones en soportes
out.deformations.get(topNode);  // [Ux, Uy, Uz, Rx, Ry, Rz]
out.reactions.get(baseNode);    // [Fx, Fy, Fz, Mx, My, Mz]
```

Tres columnas cantilever empotradas en base, L=3m, peso propio:

| Tipo | Sección ETABS | Material | Shape e2k |
|------|--------------|----------|-----------|
| **Acero** | HSS 300×300×12 mm | A572Gr50 | `Steel Tube` |

| **Mixta CFT** | HSS 300×300×12 + 4000 Psi fill | A572Gr50 + `FILLMATERIAL` | `Filled Steel Tube` |

Empotramiento total: `UX UY UZ RX RY RZ`
Carga: peso propio (kg/m) → reparto nodal equivalente
Solución analítica: $u_{top} = \frac{q L^2}{2 E A_{eq}}$

## Benchmark cantilever ACERO

**Sección HSS 300×300×12 hueco** · L=3m · A572Gr50

```
A_s = 0.30² − 0.276² = 138.24 cm²
I_s = (0.30⁴ − 0.276⁴)/12 = 19143 cm⁴
γ_s · A = 76.97 · 0.01382 = 1.064 kN/m
W = q·L = 3.193 kN
```

**Resultado analítico:**
$$u_{top} = \frac{q \cdot L^2}{2 \cdot E \cdot A_s} = \frac{1.064 \cdot 9}{2 \cdot 2 \times 10^8 \cdot 0.01382} = -1.73 \times 10^{-3} \text{ mm}$$

<span class="ok">Hekatan: -1.732e-3 mm  →  Δ vs analítico = 0.000%</span>

## Benchmark cantilever HORMIGÓN

**Sección 30×30 cm rectangular** · L=3m · concrete f'c=4000 psi

```
A   = 0.30² = 900 cm²
I   = 0.30⁴/12 = 67500 cm⁴
γ_c · A = 23.54 · 0.09 = 2.119 kN/m
W = q·L = 6.358 kN
```

**Resultado analítico:**
$$u_{top} = \frac{q \cdot L^2}{2 \cdot E \cdot A} = \frac{2.119 \cdot 9}{2 \cdot 25 \times 10^6 \cdot 0.09} = -4.24 \times 10^{-3} \text{ mm}$$

<span class="ok">Hekatan: -4.238e-3 mm  →  Δ vs analítico = 0.000%</span>

## Benchmark cantilever CFT — caso estrella

**Sección CR300×300×121mm = HSS + concreto fill 4000Psi** · L=3m

Sección transformada steel-equivalente:
```
A_eq = A_s + A_c/n = 138.24 + 761.76/8.044 = 232.93 cm²  ✓ ETABS
I_eq = I_s + I_c/n = 19143 + 48356/8.044 = 25155 cm⁴     ✓ ETABS
n = E_s/E_c = 200/24.86 = 8.044
q  = γ_s·A_s + γ_c·A_c = 1.064 + 1.795 = 2.859 kN/m
```

| Fuente | Uz top |
|--------|--------|
| ETABS API (extracción Python OAPI) | -0.00276 mm |
| Hekatan Struct Lineal | -0.00276 mm |
| Analítico $qL^2/(2EA_{eq})$ | -0.00276 mm |

## Property Modifiers ETABS-style

ETABS aplica reductores multiplicativos: `K_eff = K · modifier`

| Modifier | Aplica a | Uso típico |
|----------|----------|------------|
| `AREAMODIFIER` (A_mod) | Rigidez axial | Vigas peraltadas |
| `AS2MODIFIER` / `AS3MODIFIER` | Áreas a corte | Bernoulli puro: As=0 |
| `JMODIFIER` | Torsión Saint-Venant | Reducción por agrietamiento |
| `I22MODIFIER` / `I33MODIFIER` | Inercias flexión | NEC fisuración: 0.5/0.7 |

```typescript
A_mod:   { default: 1.0, label: "Area mod (axial)" },
I33_mod: { default: 1.0, label: "I33 mod (flexión strong)" },
// ... slider 0..1 ajustable en vivo desde Tweakpane
```

**Hekatan replica exactamente** la convención ETABS → comparación 1:1.

## Round-trip `.e2k` con ETABS

**Botón "📤 Exportar a ETABS .e2k"** en cada benchmark.

Genera archivo nativo de ETABS 19.1.0:
```
$ FRAME SECTIONS
  FRAMESECTION  "CR300X300X121mm"  MATERIAL "A572Gr50"
                SHAPE "Filled Steel Tube"  D 0.3 B 0.3
                TF 0.012 TW 0.012
                FILLMATERIAL "4000Psi"

$ POINT ASSIGNS
  POINTASSIGN  "1"  "Base"  RESTRAINT "UX UY UZ RX RY RZ"

$ LOAD PATTERNS
  LOADPATTERN "DEAD"  TYPE "Dead"  SELFWEIGHT  1
```

**Workflow del estudiante:**
1. Modela en Hekatan Struct Lineal (parámetros + sliders)
2. Click "📤 Exportar `.e2k`"
3. Abre archivo en ETABS → mismo modelo, mismos resultados
4. Compara reportes ⇒ confianza en el solver propio

## Importador `.e2k` (round-trip inverso)

**ETABS → Hekatan**: importa modelo existente y valida.

```typescript
import { parseE2k } from "./shared/e2kParser";
const model = parseE2k(rawText);   // → nodes, elements, materiales, secciones
buildExampleFromE2k(model);        // → FEM lista para `deform()`
```

Validados en proyectos reales:
